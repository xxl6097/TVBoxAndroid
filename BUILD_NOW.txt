🚀 打包步骤（在有 Android Studio 的机器上执行）

方式一：Android Studio 图形界面（推荐）
  1. 打开 Android Studio
  2. File → Open → 选择项目目录
     /Users/uuxia/WorkBuddy/2026-11-01-12-57-02/TVBoxAndroid
  3. 等待 Gradle 同步完成（首次需 5-10 分钟下载依赖）
  4. Build → Build Bundle(s) / APK(s) → Build APK(s)
  5. 点击通知栏的 "locate" 打开 APK 所在目录
  6. APK 路径：app/build/outputs/apk/debug/app-debug.apk

方式二：命令行（需要先安装 Android Studio）
  # 1. 进入项目目录
  cd /Users/uuxia/WorkBuddy/2026-11-01-12-57-02/TVBoxAndroid

  # 2. 使用内置脚本（自动检测环境）
  ./build_apk.sh

  # 3. 或直接用 Gradle Wrapper
  ./gradlew assembleDebug

  # 4. 产物位置
  ls -lh app/build/outputs/apk/debug/app-debug.apk

🐛 常见问题

Q: Gradle 同步失败
A: 删除缓存重试
   rm -rf ~/.gradle/caches/
   ./gradlew clean

Q: SDK 版本不匹配
A: 在 Android Studio 中
   Tools → SDK Manager → 安装 API 34

Q: JDK 版本不对
A: 在 Android Studio 中
   File → Settings → Build → Gradle
   选择 Gradle JDK 为 17 或更高版本

Q: 构建太慢
A: gradle.properties 已配置并行构建
   org.gradle.parallel=true
   org.gradle.caching=true
