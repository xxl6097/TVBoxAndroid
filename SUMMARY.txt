🚀 快速开始

1. 用 Android Studio 打开项目
   cd TVBoxAndroid
   open -a "Android Studio" .

2. 同步 Gradle 依赖
   点击右上角 "Sync Now"

3. 创建 TV 模拟器
   Tools → Device Manager → Create Virtual Device → TV

4. 下一步：实现 MainActivity
   参考 QUICKSTART.md 中的示例代码
