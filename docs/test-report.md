## 二、本轮发现并修复的缺陷

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 首页没有任何站源内容，点播页提示「没有返回分类」 | `cleanJson()` 把 `"class"` 改名成 `"catList"`，而模型上是 `@SerializedName("class")`，Gson 匹配不到 | 去掉改名（那是 ArkTS 的写法，Kotlin 不需要） |
| 2 | 首页左侧一条白栏，行标题与卡片不对齐、文字被裁 | `brandColor=白色` 画出了 headers 区；`HEADERS_HIDDEN/DISABLED` 在该 leanback 版本下完全不渲染内容 | 弃用 Leanback，首页改为自绘 ScrollView + 横向行 |
| 3 | 方向键只滚页面，焦点不落到卡片 | 容器可聚焦且没有初始焦点 | 容器 `focusable=false`，渲染后 `requestFocus()` 第一个可聚焦控件 |
| 4 | 点击卡片要连点两次才响应 | `isFocusableInTouchMode=true` 让首次点击只夺焦 | 去掉该属性 |
| 5 | 剧集/海报格子被拉伸成整行 | `GridLayout.spec(UNDEFINED,1,1f)` 的 weight 是按行分配 | 显式列号 + 按屏宽算固定列宽 |
| 6 | 「继续观看」卡片没有封面，续播串线路 | 写历史时没存 `vodPic`，`lineIndex` 硬编码 0 | PlayerActivity 新增两个参数并透传 |
| 7 | 焦点高亮几乎看不见 | 只换底色深浅（#33000000 → #66000000） | 改为圆角 + 2.5dp 黄色描边 |
| 8 | 每次 CI 构建签名不同，无法覆盖安装 | GitHub Actions 每次生成新的 debug keystore | 仓库内置固定 `debug.keystore` 并在 `signingConfigs.debug` 引用 |

# 第四轮：真实极空间环境验证（网盘）

用你配置的真实源（`fs.abber.cn:88/dav/迅雷下载`）跑了一遍网盘链路。

## 发现并修复

**现象**：`/电影` 目录下 4 个 `.mp4` 全部显示成文件夹图标，统计为「4 个文件夹 · 0 个视频」，
点进去是空目录，根本无法播放。

**根因**：极空间的 PROPFIND 响应不规范 ——
1. 对所有 href 都加尾斜杠（文件也加），所以「按斜杠判断目录」失效；
2. 对文件也返回 `<D:collection/>` 标签，所以「按 resourcetype 判断」同样失效。

**修复**：把目录判定改成三级优先级（`WebdavClient.parse`）：

| 顺序 | 判据 | 说明 |
|---|---|---|
| 1 | `getcontentlength > 0` | 有长度的必然是文件，最可靠 |
| 2 | href 以 `/` 结尾 | RFC 4918 规范实现 |
| 3 | `resourcetype` 含 collection | 老实现兜底 |

## 防回归

新增 `app/src/test/java/com/hong/tvbox/core/WebdavClientTest.kt`，用三段真实形状的
207 XML 固化三种服务端风格（规范 / 极空间 / 无斜杠），另含自身条目过滤、中文与
特殊字符文件名两个用例。CI 增加 `testDebugUnitTest` 步骤，已跑通。
