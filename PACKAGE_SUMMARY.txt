构建方式

方式 1: Android Studio（推荐）
  1. open -a "Android Studio" .
  2. 等待 Gradle 同步
  3. Build → Build APK(s)
  4. 产物：app/build/outputs/apk/debug/app-debug.apk

方式 2: 命令行（快速）
  ./build_apk.sh

方式 3: Gradle 直接构建
  ./gradlew assembleDebug

USB 连接
  adb install app/build/outputs/apk/debug/app-debug.apk

无线 ADB（需先配对）
  adb connect 192.168.1.x:5555
  adb install app/build/outputs/apk/debug/app-debug.apk
